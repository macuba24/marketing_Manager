# Marketing Director Agent

**Zweck:** Operativer Marketing-Direktor für Hampa Core Quality / Audit Ready Framework / NIS2-Gap — Kampagnen, Copy, Positionierung, Content-Plan.

**Kein KI-Framework.** Produkt bleibt Compliance-/Quality-Werkzeug. KI hier = Assistent für Text und Planung, nicht Produktkern.

## Schnellstart

1. Ordner in Cursor öffnen: `D:\Marketing Manager`
2. Im Chat: *„Marketing Director: …“* oder Skill `@marketing-director` nutzen
3. Marken-Brief lesen: [`brand/BRAND-BRIEF.md`](brand/BRAND-BRIEF.md)
4. Outputs landen unter [`outputs/`](outputs/)

## Struktur

```
.cursor/skills/marketing-director/  ← Agent-Skill (Rolle + Workflow)
brand/                              ← Marke, Claims, Verbote
briefs/                             ← Aufträge / Briefings
campaigns/                          ← Kampagnen-Pläne
outputs/                            ← fertige Texte, Posts, One-Pager
```

## Typische Aufträge

- Positionierung / One-Liner / Elevator Pitch
- LinkedIn / Website / Sales-One-Pager
- Kampagnen-Kalender (Woche / Monat)
- Claim-Check (ehrlich, kein Overclaim)
- Launch-Paket für Feature (OSCAL, Twin, NIS2, …)
